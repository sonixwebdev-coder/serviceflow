# Support

ServiceFlow is community-supported. Use the repository issue tracker for reproducible defects and feature proposals. Include the commit or release, deployment method, relevant sanitized logs, reproduction steps, and expected versus actual behavior.

General setup questions should use repository discussions when available. Please do not include credentials, access tokens, customer records, private URLs, database contents, or other sensitive data.

Commercial hosting, migrations, uptime commitments, incident response, custom development, and legal or compliance advice are outside upstream support. ForjaIt support applies only under its separate commercial terms and is not an upstream ServiceFlow commitment.

Potential vulnerabilities must follow [SECURITY.md](SECURITY.md), not the public issue tracker.
